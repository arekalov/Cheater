## Обзор проекта

**Cheater** — это мобильное приложение для Wear OS, предназначенное для быстрого доступа к базе знаний с вопросами и ответами. Приложение содержит **1875 уникальных вопросов** по 11 категориям с поддержкой 105 изображений.

### Ключевые возможности

- 🔍 **Умный поиск** — fuzzy matching с ранжированием результатов
- 🗂️ **11 категорий** — автоматическая категоризация вопросов
- 🖼️ **Изображения** — 105 изображений с формулами и графиками
- 🎨 **Темная тема** — оптимизация для экономии батареи на AMOLED экранах
- ⌚ **Rotary Input** — поддержка физической короны на часах
- 📴 **Офлайн режим** — все данные хранятся локально
- 🎯 **Фильтрация** — возможность фильтровать вопросы с изображениями

### Целевая аудитория

Приложение создано для студентов и специалистов, изучающих темы:
- Основы моделирования
- Теория вероятностей
- Случайные процессы
- Системы массового обслуживания (СМО)
- Имитационное моделирование
- Генерация случайных чисел

## Архитектура

### Паттерн MVI (Model-View-Intent)

Приложение использует архитектуру **MVI** для предсказуемого управления состоянием:

```
┌─────────┐     ┌──────────┐     ┌───────┐
│ Intent  │────▶│ViewModel │────▶│ State │
└─────────┘     └──────────┘     └───────┘
                      │                │
                      ▼                ▼
                ┌──────────┐     ┌───────┐
                │Repository│     │  View │
                └──────────┘     └───────┘
                      │
                      ▼
                ┌──────────┐
                │DataSource│
                └──────────┘
```

### Слои приложения

#### 1. Presentation Layer
- **Screen** — Composable функции UI
- **ViewModel** — Управление состоянием и бизнес-логикой
- **State** — Неизменяемое состояние экрана
- **Intent** — События от пользователя

#### 2. Domain Layer
- **Repository** — Абстракция над источниками данных
- **SearchEngine** — Алгоритмы поиска и ранжирования

#### 3. Data Layer
- **DataSource** — Чтение данных из JSON
- **Model** — Модели данных

#### 4. DI Layer
- **Hilt Modules** — Настройка Dependency Injection

## Структура данных

### Формат хранения

Все данные хранятся в файле `app/src/main/assets/questions.json`:

```json
{
  "questions": [
    {
      "id": "unique_id",
      "question": "Текст вопроса",
      "answer": "Текст ответа",
      "category": "Название категории",
      "keywords": ["ключевое", "слово"],
      "image": "path/to/image.jpg"
    }
  ]
}
```

### Категории

1. **Основы моделирования** — базовые понятия моделирования
2. **Случайные величины** — дискретные и непрерывные СВ
3. **Распределения** — типы распределений вероятностей
4. **Мат. ожидание и дисперсия** — характеристики СВ
5. **Случайные процессы** — процессы во времени
6. **Потоки событий** — Пуассоновские потоки
7. **СМО** — системы массового обслуживания
8. **Дисциплины обслуживания** — FIFO, LIFO, приоритеты
9. **Имитационное моделирование** — методы симуляции
10. **Генерация случайных чисел** — ГПСЧ, тесты
11. **Другое** — прочие вопросы

### Источники данных

Данные собраны из двух источников:

1. **etest-parser** (johnny-keker/etest-parser)
   - 8 HTML тестов
   - 1715 уникальных вопросов

2. **modelling_common**
   - 2 HTML файла
   - 160 дополнительных вопросов

**Обработка данных:**
- Парсинг HTML → JSON
- Дедупликация (удалено 5113 дубликатов)
- Автоматическая категоризация
- Генерация keywords для поиска
- Оптимизация изображений

## Модули приложения

### 1. Home Screen (`presentation/home/`)

**Назначение:** Главный экран с категориями и глобальным поиском

**Компоненты:**
- `HomeScreen` — UI главного экрана
- `HomeViewModel` — Управление состоянием
- `HomeState` — Состояние (категории, статистика)
- `HomeIntent` — События (навигация, поиск)

**Функциональность:**
- Отображение всех категорий
- Счетчик вопросов по категориям
- Кнопка глобального поиска

### 2. Category Screen (`presentation/category/`)

**Назначение:** Список вопросов выбранной категории

**Компоненты:**
- `CategoryScreen` — UI списка вопросов
- `CategoryViewModel` — Фильтрация и управление
- `CategoryState` — Список вопросов
- `CategoryIntent` — Навигация к вопросу

**Функциональность:**
- Отображение вопросов категории
- Lazy loading списка
- Навигация к деталям вопроса

### 3. Search Screen (`presentation/search/`)

**Назначение:** Поиск по вопросам в рамках категории

**Компоненты:**
- `SearchScreen` — UI поиска
- `SearchViewModel` — Логика поиска
- `SearchState` — Результаты поиска
- `SearchIntent` — Поисковые запросы

**Функциональность:**
- Поиск по тексту вопроса
- Fuzzy matching
- Ранжирование результатов

### 4. Global Search Screen (`presentation/global_search/`)

**Назначение:** Глобальный поиск по всем категориям

**Компоненты:**
- `GlobalSearchScreen` — UI глобального поиска
- `GlobalSearchViewModel` — Поиск по всей базе
- `GlobalSearchState` — Результаты
- `GlobalSearchIntent` — Запросы и фильтры

**Функциональность:**
- Поиск по всем вопросам
- Фильтр "только с изображениями"
- Отображение ответа в результатах
- Группировка по категориям

### 5. Question Detail Screen (`presentation/detail/`)

**Назначение:** Детальное отображение вопроса

**Компоненты:**
- `QuestionDetailScreen` — UI деталей
- `QuestionDetailViewModel` — Загрузка вопроса
- `QuestionDetailState` — Вопрос + ответ
- `QuestionDetailIntent` — Навигация

**Функциональность:**
- Полный текст вопроса
- Полный текст ответа
- Отображение изображения (если есть)
- Масштабирование изображений

### 6. Search Engine (`data/search/`)

**Алгоритм поиска:**
```kotlin
// Fuzzy matching с несколькими критериями:
1. Точное совпадение (вес: 10.0)
2. Совпадение начала слова (вес: 5.0)
3. Совпадение в keywords (вес: 3.0)
4. Совпадение подстроки (вес: 1.0)
```

**Ранжирование:**
- Результаты сортируются по релевантности
- Учитывается позиция совпадения
- Учитывается количество совпадений

## Разработка

### Установка и запуск

1. **Клонирование репозитория:**
```bash
git clone <repository-url>
cd Cheater
```

2. **Открытие в Android Studio:**
```bash
# Откройте папку проекта в Android Studio
```

3. **Настройка keystore (опционально):**
Создайте файл `keystore.properties`:
```properties
KEYSTORE_FILE=cheater-release-key.jks
KEYSTORE_PASSWORD=your_password
KEY_ALIAS=your_alias
KEY_PASSWORD=your_key_password
```

4. **Запуск в эмуляторе:**
- Создайте Wear OS эмулятор в AVD Manager
- Нажмите Run (Shift+F10)

### Добавление новых вопросов

1. Отредактируйте `etest-parser/parser_to_json.py`
2. Добавьте новые HTML файлы в соответствующие папки
3. Запустите парсер:
```bash
cd etest-parser
python parser_to_json.py
```
4. Скопируйте сгенерированный `questions.json` в `app/src/main/assets/`

### Код-стайл

- Используйте Kotlin официальный code style
- Следуйте принципам Clean Architecture
- Каждый экран должен иметь свою папку с 4 файлами: Screen, ViewModel, State, Intent

### Тестирование

```bash
# Запуск unit тестов
./gradlew test

# Запуск UI тестов
./gradlew connectedAndroidTest
```

## Сборка и развёртывание

### Debug сборка

```bash
./gradlew assembleDebug
```

APK файл: `app/build/outputs/apk/debug/app-debug.apk`

### Release сборка

```bash
./gradlew assembleRelease
```

APK файл: `app/build/outputs/apk/release/app-release.apk`

### Установка на устройство

#### Через USB:
```bash
adb install app-release.apk
```

#### Через Wi-Fi:
```bash
# Получите IP адрес часов в Settings → Connectivity → Wi-Fi
adb connect <IP_ADDRESS>:5555
adb install app-release.apk
```

### CI/CD (GitHub Actions)

При push в `master`/`main` ветку автоматически:
1. Собирается release APK
2. Подписывается ключом из secrets
3. Создаётся GitHub Release (при наличии тега)

**Создание релиза:**
```bash
git tag v1.1.0
git push origin v1.1.0
```

### Секреты для CI/CD

Настройте в GitHub Secrets:
- `KEYSTORE_BASE64` — base64 закодированный keystore
- `KEYSTORE_PASSWORD` — пароль keystore
- `KEY_ALIAS` — alias ключа
- `KEY_PASSWORD` — пароль ключа

## Производительность

### Оптимизации

1. **Lazy Loading** — вопросы загружаются постепенно
2. **Image Caching** — изображения кэшируются в памяти
3. **State Management** — минимизация перерисовок UI
4. **Coroutines** — асинхронная работа без блокировки UI
5. **KSP вместо KAPT** — ускорение сборки на 25%

### Размер APK

- **Debug**: ~3.5 MB
- **Release**: ~2.8 MB (с ProGuard)

### Потребление памяти

- **Idle**: ~40 MB RAM
- **Active search**: ~60 MB RAM
- **Image viewing**: ~80 MB RAM
